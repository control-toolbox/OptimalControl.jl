Lift ​

Given a vector field   , its Hamiltonian lift is the function     defined by

It is an algebraic construction: no derivative is computed.

julia
using OptimalControl
using OrdinaryDiffEqTsit5

From a plain function ​

julia
X(x) = [x[2], -x[1]]
H = Lift(X)

x, p = [1.0, 2.0], [3.0, 4.0]
H(x, p)   # 3 × 2 + 4 × (-1)
2.0

The lift of a plain function is a function, not a Hamiltonian:

julia
H isa Function, H isa AbstractHamiltonian
(true, false)

From a typed vector field ​

The lift of a VectorField is a Hamiltonian, with the same dependence on time and on the variable as the vector field:

julia
XV = VectorField(x -> [x[2], -x[1]])
HV = Lift(XV)
HV isa AbstractHamiltonian, HV(x, p)
(true, 2.0)

Time and variable ​

For a vector field , pass is_autonomous=false, and the lift is called as . With   ,       :

julia
Ht = Lift((t, x) -> [t * x[2], -x[1]]; is_autonomous=false)
Ht(2.0, x, p)
8.0

For a vector field , pass is_variable=true, and the lift is called as . With    ,       :

julia
Hv = Lift((x, v) -> [x[2] + v, -x[1]]; is_variable=true)
Hv(x, p, 1.0)

A Hamiltonian vector field cannot be lifted ​

A HamiltonianVectorField already lives on the cotangent space, so Lift rejects it. The message names ad instead of Lift (CTLie#41):

julia
julia> Lift(HamiltonianVectorField((x, p) -> (p, -x)))
NotImplemented → top-level scope, REPL[1]:2
│
│  ad on AbstractHamiltonianVectorField is not implemented (signature is (x,p), not (x))
│
│  Context  ad on AbstractVectorField
│  Hint     Use ad on a plain VectorField
└─
