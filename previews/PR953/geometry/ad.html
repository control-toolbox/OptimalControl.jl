Typed operands and nested brackets ​

On VectorFields, ad returns a VectorField, which can be bracketed again. The bracket at   is  :

julia
XV = VectorField(x -> [x[2], -x[1]])
YV = VectorField(x -> [x[1]^2, x[2]^2])

ZV = ad(XV, YV)
ZV isa VectorField, ad(ZV, YV)([1.0, 2.0])
(true, [4.0, -2.0])

The macro @Lie writes the same bracket @Lie [[XV, YV], YV].

Partial time derivative ​

For a function , ∂ₜ(f) computes the partial derivative with respect to time:

With   ,    at  :

julia
g(t, x) = t^2 + x[1] * x[2]
dg = ∂ₜ(g)
dg(3.0, [1.0, 2.0])
6.0

∂ₜ also applies to a VectorField or a Hamiltonian. Its result always depends on time, even when the input does not, and is then zero:

julia
dXV = ∂ₜ(XV)
dXV(1.0, [1.0, 2.0])
2-element Vector{Float64}:
 0.0
 0.0

Together with the Poisson bracket, ∂ₜ gives the time derivative of a function along an extremal (see Poisson bracket).
