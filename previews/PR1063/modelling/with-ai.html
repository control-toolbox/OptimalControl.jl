With AI ​

An AI assistant can learn the syntax of OptimalControl.jl from this documentation, then translate a problem written in mathematics into code that you run. This page gives prompts to copy into your assistant: open it, paste the first prompt, then the others as you need them, in the same conversation.

Teach the assistant ​

Start with this prompt. It points to three pages: the syntax of @def, how to solve a problem, and how to read its solution.

text
Learn the syntax of the OptimalControl.jl DSL (Julia language) to translate math into this DSL,
and how to solve a problem and read its solution, from these pages:
https://control-toolbox.org/OptimalControl.jl/stable/modelling/abstract-syntax
https://control-toolbox.org/OptimalControl.jl/stable/solve/overview
https://control-toolbox.org/OptimalControl.jl/stable/results/solution
Open:ChatGPTClaudeCopilotGeminiMistralPerplexity

The buttons open an assistant with this prompt filled in, when the assistant accepts it from the link; otherwise, or if the message box is empty, paste the prompt above. Some assistants ask you to sign in first.

The assistant must be able to open web pages. If it cannot, it answers from what it already knows, which may be an older syntax: check that its answer mentions what is on these pages.

Translate a problem ​

Give the problem as you would write it on paper:

text
Translate the problem below into this DSL:

    minimise the final time tf
    under the constraint q''(t) = u(t)
    with -1 <= u(t) <= 1,
    q(0) = 1, q'(0) = -2, q(tf) = 3, q'(tf) = 1, and q'(t) <= 1.

The problem can also be given in LaTeX, or as an image or a PDF attached to the message, if your assistant accepts files:

text
Translate the problem in the attached image into this DSL.

Ask for more ​

In the same conversation, ask for the rest of the work, for instance:

text
Solve the problem with a grid of 500 steps, check that the solver succeeded,
and print the final time.
text
Label the constraint q'(t) <= 1, and plot its multiplier.
text
Plot the solution.
text
Give me the values you expect for the final time and the cost,
so that I can compare them with the numerical solution.

Check the answer ​

Run the code, and check what the assistant says

An assistant does not run the code it writes, and its explanations may be wrong even when its code is right. In our tests, with ChatGPT in November 2026:

  • for the problem above, the code was right, but the assistant announced  , with   on the whole interval: then   , not . The solution is  , with a boundary arc where  ;

  • taught with the syntax page only, the assistant forgot to declare the final time, tf ∈ R, variable, before using it in t ∈ [0, tf], time, and the model did not build: this is why the first prompt gives three pages;

  • an answer read the solution with state(sol)[1](t), which does not exist: the state is a function of time, so write state(sol)(t)[1].

Run the code, check successful(sol), compare with a value you know, and plot the solution (see Solution object).
