Errors ​

OptimalControl raises a few typed exceptions. Each one says what went wrong (Got, Expected, Reason), where (Context), and how to fix it (Hint), so the message is the first thing to read. This page lists them, with a real example of each.

ExceptionWhat it meansUsual cause
IncorrectArgumentan argument is invalida wrong value, size or name, an unknown option
AmbiguousDescriptiona method description matches no known methoda misspelt or unavailable token in solve(ocp, :token)
ParsingErrora @def or @init block cannot be reada syntax the macro does not know
PreconditionErrorthe arguments are valid, but the call is not allowed nowa value the object does not hold, a call in the wrong order
ExtensionErrora feature needs a package that is not loadedusing NLPModelsIpopt, Plots, OrdinaryDiffEqTsit5, … missing
SolverFailurean integration faileda trajectory that blows up, a stiff problem
NotImplementeda method is missing for this typean extension point not implemented: please report it

All of them are subtypes of OptimalControl.CTException.

IncorrectArgument ​

An option that no strategy of the method knows. The hint lists the closest names:

julia> solve(ocp; tolerance=1e-8)
ERROR: IncorrectArgument
│
│  Unknown option provided
│
│  Got       option :tolerance in method (:collocation, :adnlp, :ipopt, :cpu)
│  Expected  valid option name for one of the strategies
│
│  Context   route_options - unknown option validation
│  Hint      Did you mean?
│              - :tol [distance: 6]
│              - :name [distance: 7]
│              - :scheme (alias: disc_method) [distance: 7]
│            If you're confident this option exists for a specific strategy, use bypass() to skip validation:
│              custom_opt = route_to(<strategy_id>=bypass(<value>))
└─

ParsingError ​

A line of @def that matches no syntax (see Abstract syntax):

julia> @def begin
           t ∈ [0, 1], time
           x ∈ R, state
           u ∈ R, control
           x(0) == 0
           ẋ(t) == u(t)
           ∫(u(t)^2) → minimise
       end
ERROR: ParsingError
│
│  
│  Line 6: ∫(u(t) ^ 2) → minimise
│  unknown syntax
└─

PreconditionError ​

The solution of a flow carries no multiplier of the boundary conditions (see Constrained arcs):

julia> sol = Flow(ocp, (x, p) -> p[2])((0, 1), [-1, 0], [12, 6]);

julia> dual(sol, ocp, :start)
ERROR: PreconditionError
│
│  the solution carries no dual variables
│
│  Reason   the solution's dual model is empty (EmptyDualModel)
│
│  Context  dual - looking up a constraint dual on a dual-free solution
│  Hint     This solution comes from a CTFlows flow, which rebuilds the duals of the path constraints only, from the multiplier given with constraint=:label. The duals of the boundary and box constraints are not computed by a flow (see control-toolbox/CTFlows.jl#495).
└─

ExtensionError ​

The error names the package to load: see Installation for an example, and for the packages each feature needs.

Catching an error ​

The exceptions are reached as OptimalControl.X, so a script can catch one by its name and let the others through:

julia
function final_state_or_nothing(x0)
    try
        return Flow(VectorField(x -> x^2))(0, x0, 2)
    catch e
        e isa OptimalControl.SolverFailure || rethrow()
        return nothing
    end
end
final_state_or_nothing(-1.0), final_state_or_nothing(1.0)
(-0.3333333353095414, nothing)
