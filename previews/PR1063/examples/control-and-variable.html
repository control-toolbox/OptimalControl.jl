Control and variable together ​

1 or 2 states1 control1 parameterBolza cost

Some problems optimise a control and constant parameters at the same time: to identify a parameter and the input that explains the data, or to find a parameter and the control law that go best together. This page takes the two systems of Parameter estimation without a control, and adds a control to their dynamics, with a quadratic cost. The method is the same; this page shows what the control changes.

We load OptimalControl and the packages that the direct and indirect methods need:

julia
using OptimalControl        # define the problem, solve it, build the flows
using NLPModelsIpopt        # NLP solver of the direct method
using OrdinaryDiffEqTsit5   # integrator of the flows
using NonlinearSolve        # solver of the shooting equations
using Plots                 # plots of the solutions

Growth rate, with a control ​

The problem ​

The growth model gets an additive control,   , and the cost a term : the control can explain the part of the data that the model does not, at a price.

julia
λ_true = 0.5
x_obs(t) = 2 * exp(λ_true * t) + 0.2 * sin(4π * t)

t0, tf, x0 = 0, 2, 2

ocp_growth = @def begin
    λ ∈ R, variable
    t ∈ [t0, tf], time
    x ∈ R, state
    u ∈ R, control

    x(t0) == x0

    ẋ(t) == λ * x(t) + u(t)

    ∫((x(t) - x_obs(t))^2 + 0.5u(t)^2) → min
end

u_growth(t, x, p, λ) = p
f_growth = Flow(ocp_growth, u_growth)

function shoot_growth!(s, ξ, _)
    p0, λ = ξ
    _, p_tf, pλ_tf = f_growth(t0, x0, p0, tf; variable=λ, variable_costate=true)
    s[1] = p_tf      # free final state
    s[2] = pλ_tf     # free parameter
    return nothing

julia
q0, v0 = 1, 0
t0h, tfh = 0, 1

ocp_harmonic = @def begin
    ω ∈ R, variable
    t ∈ [t0h, tfh], time
    x = (q, v) ∈ R², state
    u ∈ R, control

    q(t0h) == q0
    v(t0h) == v0
    q(tfh) == 0

    ẋ(t) == [v(t), -ω^2 * q(t) + u(t)]

    ω^2 + 0.5∫(u(t)^2) → min
end

julia
u_harmonic(x, p, ω) = p[2]
f_harmonic = Flow(ocp_harmonic, u_harmonic)

function shoot_harmonic!(s, ξ, _)
    p0, ω = ξ[1:2], ξ[3]
    x_tf, p_tf, pω_tf = f_harmonic(t0h, [q0, v0], p0, tfh; variable=ω, variable_costate=true)
    s[1] = x_tf[1]        # q(tf) = 0
    s[2] = p_tf[2]        # free final velocity
    s[3] = pω_tf + 2ω     # transversality of the parameter
    return nothing
end

ξ_guess_h = [costate(harmonic_sol)(t0h)..., variable(harmonic_sol)]
prob_harmonic = NonlinearProblem(shoot_harmonic!, ξ_guess_h)
shooting_harmonic = NonlinearSolve.solve(prob_harmonic; show_trace=Val(false))
p0_harmonic, ω_sol = shooting_harmonic.u[1:2], shooting_harmonic.u[3]

Applications ​

Problems with a control and parameters appear in many contexts:

  • system identification: estimating physical parameters (mass, damping, stiffness) and the inputs, from experimental data;

  • optimal design: finding geometric or physical parameters together with the control law that goes with them;

  • inverse problems: reconstructing unknown inputs or initial conditions from partial observations, while optimising parameters of the system.

See also ​

  • Parameter estimation without a control: the same two systems, without a control, and the derivation of the augmented system.
