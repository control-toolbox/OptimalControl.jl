Parameter estimation without a control ​

1 or 2 statescontrol-free1 parameterdata fitting

A problem without a control optimises constant parameters of a dynamical system: the parameters that make a model fit observed data, or the best parameters for a performance criterion. This page solves two such problems, by the direct and the indirect methods: the growth rate of an exponential model fitted to data, and the smallest pulsation of an oscillator that reaches a target. Control-free problems explains how to write them.

We load OptimalControl and the packages that the direct and indirect methods need:

julia
using OptimalControl        # define the problem, solve it, build the flows
using NLPModelsIpopt        # NLP solver of the direct method
using OrdinaryDiffEqTsit5   # integrator of the flows
using NonlinearSolve        # solver of the shooting equations
using Plots                 # plots of the solutions

Growth rate ​

The problem ​

A quantity grows exponentially,  , from  , at an unknown rate . We observe it on , and the observations are the model with  , perturbed by a small oscillation. We estimate by least squares. The estimate is close to , but not equal, because of the perturbation.

julia
λ_true = 0.5
x_obs(t) = 2 * exp(λ_true * t) + 0.2 * sin(4π * t)

t0, tf, x0 = 0, 2, 2

ocp_growth = @def begin
    λ ∈ R, variable
    t ∈ [t0, tf], time
    x ∈ R, state

    x(t0) == x0

    ẋ(t) == λ * x(t)

    ∫((x(t) - x_obs(t))^2) → min
end

f_growth = Flow(ocp_growth)

function shoot_growth!(s, ξ, _)
    p0, λ = ξ
    _, p_tf, pλ_tf = f_growth(t0, x0, p0, tf; variable=λ, variable_costate=true)
    s[1] = p_tf      # free final state
    s[2] = pλ_tf     # free parameter
    return nothing
end

The direct solution gives the initial guess:

julia

p0_growth, λ_sol = NonlinearSolve.solve(prob_growth; show_trace=Val(false)).u
p0_growth = 0.058478510530349026
λ_sol = 0.4966212669628473

Comparison ​

The two estimates differ in the third decimal: the direct method solves a discretised problem, on a grid of 20 steps, and the indirect method the problem itself.

julia

λ_sol = 0.4966212669628473
julia
indirect_growth = f_growth((t0, tf), x0, p0_growth; variable=λ_sol)
plot!(plt_growth, indirect_growth, :state; label="indirect", linestyle=:dash)

The problem ​

julia
q0, v0 = 1, 0
t0h, tfh = 0, 1

ocp_harmonic = @def begin
    ω ∈ R, variable
    t ∈ [t0h, tfh], time
    x = (q, v) ∈ R², state

    q(t0h) == q0
    v(t0h) == v0
    q(tfh) == 0

    ẋ(t) == [v(t), -ω^2 * q(t)]

    ω^2 → min
end

f_harmonic = Flow(ocp_harmonic)

function shoot_harmonic!(s, ξ, _)
    p0, ω = ξ[1:2], ξ[3]
    x_tf, p_tf, pω_tf = f_harmonic(t0h, [q0, v0], p0, tfh; variable=ω, variable_costate=true)
    s[1] = x_tf[1]        # q(tf) = 0
    s[2] = p_tf[2]        # free final velocity
    s[3] = pω_tf + 2ω     # transversality of the parameter
    return nothing
end

ξ_guess_h = [costate(harmonic_sol)(t0h)..., variable(harmonic_sol)]
prob_harmonic = NonlinearProblem(shoot_harmonic!, ξ_guess_h)
shooting_harmonic = NonlinearSolve.solve(prob_harmonic; show_trace=Val(false))
p0_harmonic, ω_sol = shooting_harmonic.u[1:2], shooting_harmonic.u[3]

Applications ​

Problems without a control appear in many contexts:

  • system identification: estimating physical parameters (mass, damping, stiffness) from experimental data;

  • optimal design: finding geometric or physical parameters (a length, a stiffness) that optimise a criterion;

  • inverse problems: reconstructing unknown inputs or initial conditions from partial observations.
