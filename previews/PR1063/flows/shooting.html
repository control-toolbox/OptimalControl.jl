Shooting ​

The maximum principle gives the extremals, but not the initial costate, the switching times or a free final time. Shooting finds them: write the conditions the extremal must satisfy as equations in these unknowns, integrate the flows to evaluate them, and solve the equations with a nonlinear solver. The direct method gives the starting point.

This page is about the method. The example Time minimisation (bang–bang) tells the whole story of the problem used here, from the derivation of the exact solution to the comparison of the direct and indirect solutions.

julia
using OptimalControl
using OrdinaryDiffEqTsit5
using NonlinearSolve
using NLPModelsIpopt

Unknowns and conditions ​

A shooting function has as many unknowns as conditions. Each unknown comes with the condition that fixes it:

UnknownCondition
initial costate the final conditions on the state, and the transversality conditions on the costate for the components the problem leaves free
a switching time the switching function vanishes at
the entry and exit times of a boundary arcthe junction conditions (see Constrained arcs)
a free final time the transversality condition on the maximised Hamiltonian at
a variable that enters the dynamics or the costits transversality condition, on the costate of the variable (see From an OCP)

The structure of the extremal, the sequence of its arcs, is not an unknown: it is chosen first, from the maximum principle or from a direct solution, and the shooting function is written for it.

The shooting function ​

The problem of this page is the minimum-time transfer of the double integrator, whose extremal is    then   :

The problem, and its two arcs
julia
t0 = 0
x0 = [-1, 0]
xf = [0, 0]

ocp = @def begin
    tf ∈ R, variable
    t ∈ [0, tf], time
    x = (q, v) ∈ R², state
    u ∈ R, control
    -1 ≤ u(t) ≤ 1
    x(0) == x0
    x(tf) == xf
    ẋ(t) == [v(t), u(t)]
    tf → min
end

f_max = Flow(ocp, (x, p, v) -> 1; label="u = +1")
f_min = Flow(ocp, (x, p, v) -> -1; label="u = -1")

The shooting function integrates the two arcs and returns the four residuals. It is written in place, as NonlinearSolve expects:

julia
H(x, p, u) = p[1] * x[2] + p[2] * u   # p ⋅ f(x, u)

function shoot!(s, ξ, _)
    p0, t1, tf = ξ[1:2], ξ[3], ξ[4]
    x1, p1 = f_max(t0, x0, p0, t1; variable=tf, unsafe=true)
    x2, p2 = f_min(t1, x1, p1, tf; variable=tf, unsafe=true)
    s[1:2] = x2 - xf             # target
    s[3] = p1[2]                 # switching function at t1
    s[4] = H(x2, p2, -1) - 1     # transversality, free final time
    return nothing
end

unsafe=true ​

While it searches, a nonlinear solver tries unknowns that are far from the solution, and the integration can fail on them. By default a flow then raises an error, which would stop the search. Where the initial guess comes from ​

A shooting method converges from a good initial guess, and the direct method provides one:

  • the initial costate is the costate of the direct solution at the initial time, costate(sol)(t0): it is accurate to the step of the grid, which is enough for the shooting to converge;

  • a switching time is where the switching function, evaluated on the costate of the direct solution, changes sign;

  • the final time, and the other variables, are variable(sol).

julia
sol_d = solve(ocp; display=false)

p_d = costate(sol_d)
tg = time_grid(sol_d)

p0_guess = p_d(t0)
t1_guess = tg[findfirst(t -> p_d(t)[2] < 0, tg)]
tf_guess = variable(sol_d)

ξ_guess = [p0_guess; t1_guess; tf_guess]
4-element Vector{Float64}:
 0.9999999963782972
 0.9942579851681156
 0.999999996378291
 1.999999992756582

Other sources are a previous shooting solution, on a nearby problem (discrete continuation), or values computed by hand on a simpler problem.

Solving the shooting equations ​

julia
prob = NonlinearProblem(shoot!, ξ_guess)
sol = NonlinearSolve.solve(prob, SimpleNewtonRaphson(); abstol=1e-10, reltol=1e-10)
p0_s, t1_s, tf_s = sol.u[1:2], sol.u[3], sol.u[4]
sol.u, sol.retcode
([0.9999999999999999, 1.0, 1.0000000000000002, 2.0000000000000004], SciMLBase.ReturnCode.Success)

Checking the solution ​

A zero of the shooting function satisfies the conditions that were written, and nothing else. A few checks make sure it is an extremal of the problem.

The residuals vanish.

julia
s = zeros(4)
shoot!(s, sol.u, nothing)
s

The concatenation of the arcs reaches the target. The point call of a concatenation returns the pair (x, p) (see Multi-phase flows):

julia
f_bb = f_max * (t1_s, f_min)
xf_s, pf_s = f_bb(t0, x0, p0_s, tf_s; variable=tf_s)
